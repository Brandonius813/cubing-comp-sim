# UI assets

The Figma design uses Geist, Geist Mono, Material Design icons, and cubing/icons.

- `geist-variable.woff2`: unmodified `fonts/Geist/webfonts/Geist[wght].woff2` from https://github.com/vercel/geist-font
- `geist-mono-variable.woff2`: unmodified `fonts/GeistMono/webfonts/GeistMono[wght].woff2` from the same repository. See `Geist-OFL.txt`.
- `event-*.svg`: unmodified event SVG files from https://github.com/cubing/icons/tree/main/src/svg. FTO comes from `unofficial/fto.svg`. See `cubing-icons-LICENSE.txt`.
- `account.svg`, `settings.svg`, `help.svg`, `chevron.svg`, `minus.svg`, and `close.svg`: unmodified 24px Material icon files from https://github.com/google/material-design-icons. See `material-icons-LICENSE.txt`.

Direct Figma asset downloads were unavailable in the build workspace. The source libraries named by the design were used. Geometry, weight, and colors still require screenshot review against Figma before final visual approval. SVG files are displayed as external images; no icon paths were recreated. CSS colors the monochrome source images for the dark theme.

Scramble diagrams are generated by the local scramble engine and are not static design assets.

- `wca-logo.svg`: unmodified official Positive Primary WCA symbol from https://github.com/thewca/worldcubeassociation.org/blob/ec2adb7bf1dab834d955af448e7efc6a00a8d05a/app/webpacker/components/StaticPages/LogoImages/1%20Positive%20Primary/WCA%20Logo.svg. Used to identify WCA sign-in, not to imply endorsement. See https://www.worldcubeassociation.org/logo.
