# Cubing Comp Sim

A focused cubing app for warming up for and simulating a WCA competition. The intended experience is to open the app and get going with minimal setup.

**Status:** public repository and project foundation are in place. No application code has been started.

## Project guide

- Start with [`PROJECT_NOTES.md`](PROJECT_NOTES.md) for the product intent, ordered checkpoints, current decisions, and open work.
- Read [`AGENTS.md`](AGENTS.md) before making changes. It describes how to keep work small, public-safe, and understandable to the project owner.
- The approved first repository choices are a public GitHub home and GitHub Issues/Projects for work tracking. Remaining engineering decisions are open until recorded in `PROJECT_NOTES.md`.
